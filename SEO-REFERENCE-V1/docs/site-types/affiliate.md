# Affiliate / Review Site SEO Playbook

## Core risk

Affiliate monetization is not inherently spam, but thin pages that add no value beyond merchant feeds/rewritten product descriptions are weak. Review/comparison sites need independent evidence, transparent methodology and clear commercial disclosure.

## High-value page types

- hands-on reviews with disclosed testing methodology;
- comparisons with current specifications/pricing;
- best-for-use-case guides with explicit selection criteria;
- long-term ownership/testing updates;
- calculators/tools/data-backed buying aids.

## Evidence standards

When claiming first-hand use, actually test the product/service and document:
- test environment;
- criteria;
- samples/duration;
- measurements;
- photos/screenshots where possible;
- limitations/conflicts of interest;
- update date/version.

Never invent tests, quotes, reviews or “we bought X” evidence.

## Affiliate links

Disclose commercial relationships clearly for users and follow applicable laws/platform rules. Link qualification should reflect paid/affiliate relationships (commonly `rel="sponsored"`, with other values as context requires). Do not hide sponsorship to pass ranking signals.

## Product updates

Maintain current prices/specs/availability where stated. If exact values change frequently, explain timing/source rather than presenting stale precision.

## Architecture

`Category hub → use-case/comparison guides → individual reviews → supporting how-to content`

Avoid thousands of thin generated “X vs Y” pairs without actual comparative evidence.

## Authority

Earn references through unique test data, benchmark methodology, tools and transparent research — not link exchanges with other affiliate networks.

## YMYL sensitivity

For health/finance/safety-related affiliate topics, raise evidence/expert-review thresholds dramatically. Commercial incentives must not override safety/accuracy.

## KPI stack

- qualified organic sessions;
- merchant click-through;
- revenue/conversion by query/page type;
- return users/newsletter;
- rankings for commercial-intent clusters;
- earned links to original tests/data;
- content freshness/accuracy defects.

## PASS gate

PASS when users gain material decision value beyond merchant pages, affiliate relationships are disclosed/qualified, testing claims are genuine, comparisons are current/fair and no scaled thin-comparison factory exists.
