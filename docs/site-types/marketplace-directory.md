# Marketplace / Directory SEO Playbook

## Core challenge

Marketplaces/directories can create enormous indexable inventories. Search value comes from real entities/inventory and useful aggregation — not from generating every filter/location/category permutation.

## Architecture

`Home → Category → Region/meaningful facet hubs → Entity/listing detail`

Define an indexability matrix for filters before launch.

## Listing quality

Each indexable entity page should have meaningful distinct data such as:
- verified identity/contact/location;
- inventory/services/features;
- current price/availability where applicable;
- genuine reviews;
- rich media;
- policies/logistics;
- structured attributes users can compare.

Thin autogenerated profiles with only a name/category should not automatically be indexed.

## Category/aggregation pages

A useful category page provides real selectable inventory, meaningful sorting/filtering, localized/category context where needed and stable crawlable pagination. It should not be an empty shell generated for a keyword.

## Facets

Maintain explicit matrix:
- indexable high-value combinations;
- user-useful but noindex combinations;
- crawl-suppressed infinite states;
- canonical clean parameter/order policy.

Monitor logs for combinatorial crawl waste.

## UGC/listing moderation

Control:
- spam/fake businesses;
- duplicate entities;
- fake reviews;
- keyword-stuffed titles;
- harmful links;
- stale/closed listings;
- user-uploaded malware/unsafe content.

## Structured data

Use entity/product/local/event/review types only when facts are visible and meet engine policies. Do not mark aggregate ratings you cannot substantiate.

## Authority

Marketplaces can earn links through valuable unique inventory/data, research, trend reports, public APIs/tools and genuine ecosystem partnerships.

## KPI stack

- useful indexable listings/categories;
- indexed vs submitted by class;
- zero-value indexed URL rate;
- crawl share by facet/template;
- organic leads/transactions;
- listing freshness/verification;
- spam/review-abuse rate;
- entity/category conversion.

## PASS gate

PASS when URL growth tracks real inventory/user value, facets are finite and intentional, listings are moderated/current, thin entities are kept out of the index, and organic success is measured by transactions/leads rather than page count.
