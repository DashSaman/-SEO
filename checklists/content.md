# Content Quality Checklist

## Intent
- [ ] Primary user job stated in one sentence.
- [ ] Target query cluster maps to this page type in current SERP.
- [ ] Informational/commercial/local/transactional intent is not mixed accidentally.
- [ ] Page has a clear next action appropriate to intent.

## Value / originality
- [ ] Page adds something beyond paraphrasing competitors.
- [ ] First-party evidence/data/examples included where available.
- [ ] Claims are sourced or clearly identified as opinion/experience.
- [ ] Limitations/tradeoffs are disclosed.
- [ ] No fabricated testing, customers, quotes, reviews or statistics.
- [ ] No arbitrary word-count filler.

## Accuracy / trust
- [ ] Facts, prices, versions and availability are current.
- [ ] Author/reviewer identity is appropriate where relevant.
- [ ] Credentials are verifiable and not exaggerated.
- [ ] High-stakes/YMYL content has stronger source/review requirements.
- [ ] Corrections/update owner exists for time-sensitive content.

## Structure
- [ ] Title and H1 accurately describe content.
- [ ] Headings follow logical information hierarchy.
- [ ] Important answer/evidence is not hidden behind unnecessary interaction.
- [ ] Tables/lists/media are used only when they improve comprehension.
- [ ] Internal links help users continue the task.
- [ ] Images/video have context and accessible descriptions where needed.

## Search safety
- [ ] No keyword stuffing.
- [ ] No doorway/location synonym pages without distinct value.
- [ ] No mass AI/spun/scraped content published without quality gate.
- [ ] No fake freshness/date changes.
- [ ] No hidden text or crawler-only answer blocks.
- [ ] Affiliate/sponsored relationships disclosed where applicable.

## AI-assisted content
- [ ] Human/editorial owner verified factual claims.
- [ ] Citations/sources checked directly.
- [ ] Hallucinated entities/references removed.
- [ ] AI assistance did not create scaled low-value page classes.
- [ ] Page is written for users, not artificial “LLM chunk” folklore.

## Measurement
- [ ] Baseline impressions/clicks/conversions captured if existing page.
- [ ] Update/deploy date annotated.
- [ ] Query mix reviewed after sufficient observation period.
- [ ] Conversion/lead/revenue quality considered, not traffic only.

## PASS
Content passes only when intent, accuracy, differentiated value and trust are all satisfied. A green plugin/content score alone is not PASS.
