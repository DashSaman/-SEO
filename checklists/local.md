# Local SEO Checklist

- [ ] Google Business Profile ownership/verification secured.
- [ ] Real business name used; no keyword stuffing.
- [ ] Address/service area accurate.
- [ ] Phone/site/hours accurate.
- [ ] Primary/secondary categories match real services.
- [ ] Services/products/attributes current.
- [ ] Real photos/media current where useful.
- [ ] Website NAP matches authoritative profiles.
- [ ] Location pages exist only for real useful location/service distinctions.
- [ ] Location pages contain unique local proof, not city-name swaps.
- [ ] LocalBusiness schema matches visible business facts.
- [ ] Reviews are genuine; no buying/gating/fake accounts.
- [ ] Review response process exists.
- [ ] Relevant local/industry citations claimed selectively.
- [ ] Duplicate/fake GBP/listings resolved.
- [ ] Local commercial queries mapped to correct service/location pages.
- [ ] Local pack and localized organic results measured separately.
- [ ] Rank measurement includes actual geography/grid/context where possible.
- [ ] Calls/directions/forms/bookings tracked.
- [ ] Strategy acknowledges Google’s relevance/distance/prominence framing.

## PASS
PASS when business/location facts are truthful, reputation is authentic, web/GBP entities align and measurement reflects local context rather than a single global rank.
