# Backlinks / Digital PR Checklist

## Prospect/value
- [ ] Link/mention opportunity serves a real audience.
- [ ] Target site/page is topically or institutionally relevant.
- [ ] Pitch is based on genuine evidence/resource/news.
- [ ] We are not buying a followed link for ranking.
- [ ] No PBN/link-farm/automated package.
- [ ] No excessive reciprocal-link scheme.

## Asset
- [ ] Original data/tool/case study/resource is accurate.
- [ ] Methodology/source/date disclosed.
- [ ] Stable canonical landing URL.
- [ ] Claims independently verifiable.
- [ ] No fabricated experts/customers/statistics.

## Relationship / disclosure
- [ ] Sponsorship/payment disclosed.
- [ ] Paid links appropriately qualified (`sponsored`/`nofollow` as context requires).
- [ ] Affiliate relationship disclosed.
- [ ] Publisher retains editorial independence.

## Competitor gap
- [ ] Gap source classified: editorial/directory/partner/paid/spam.
- [ ] We understand why competitor earned/reference deserved link.
- [ ] Spam/PBN prospects excluded.
- [ ] We do not clone anchors at scale.

## Disavow
- [ ] Manual action/link-history evidence checked first.
- [ ] Third-party toxicity score alone is not used as trigger.
- [ ] Google’s current necessity criteria reviewed.
- [ ] Existing disavow file backed up before any change.
- [ ] Changes documented and owner-approved.

## Measurement
- [ ] Relevant referring domains tracked.
- [ ] Referral traffic tracked.
- [ ] Brand mentions/branded demand tracked.
- [ ] Assisted conversions tracked.
- [ ] Ranking movement not attributed causally to one link without evidence.

## PASS
PASS when link work is editorial/user justified, policy-safe, transparent and measured beyond raw link count.
