# Tehran Network Pilot / پایلوت تهران نتورک

Pilot: Tehran Network / tehnet.ir
Mode: Build / Site Factory, then Growth
Purpose: validate completing an incomplete site through adaptive questioning and inferred brand/business context before continuous growth work.

هدف: اعتبارسنجی Site Factory روی سایتی که ممکن است ناقص باشد؛ Agent ابتدا دارایی‌های موجود را کشف می‌کند، سپس فقط سؤال‌هایی را از کاربر می‌پرسد که نتوانسته از سایت، ریپو، شبکه‌های اجتماعی و منابع مجاز استنباط کند. بعد Manifest، معماری، Design/Content Completion و QA انجام می‌شود و سایت وارد Growth Mode می‌شود.

Initial scope: asset discovery, adaptive interview, manifest, architecture, design/content completion, QA, launch readiness, then Growth Mode.

Credentials: never stored here.

## Planned non-secret records
- `site.manifest.yaml`
- `brand.yaml`
- `competitors.yaml`
- `channels.yaml`
- experiments, reports and history

## Operator documentation contract / قرارداد مستندسازی
Any reusable connector/component used for this pilot must record: purpose; why selected; version; prerequisites; installation; configuration; ports/network exposure; secret variable names only; verification; normal operation; update procedure; backup/restore; rollback; common failures; removal procedure; upstream repository and license.
