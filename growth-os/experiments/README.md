# Experiments / آزمایش‌ها

Purpose: store measured SEO, content, social, CRO, routing, and automation experiments for MyTel, Tehran Network, and future sites.

هدف: ثبت آزمایش‌های واقعی SEO، محتوا، شبکه‌های اجتماعی، CRO، AI Routing و Automation برای پایلوت‌ها و مشتری‌های آینده.

## Experiment record
Each meaningful experiment should record: hypothesis; target query/page/channel; baseline date and metrics; action/change; deployment date; cost; observed result; confidence/limitations; keep/revert/iterate decision.

هر آزمایش باید فرضیه، هدف، Baseline، تغییر انجام‌شده، تاریخ انتشار، هزینه، نتیجه، محدودیت و تصمیم Keep/Revert/Iterate را ثبت کند.

## Operator documentation contract / قرارداد مستندسازی
Reusable tooling referenced here must also record: purpose; why selected; version; prerequisites; installation; configuration; ports/network exposure; secret variable names only; verification; normal operation; update procedure; backup/restore; rollback; common failures; removal procedure; upstream repository and license.
